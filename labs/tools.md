# Tools & Setup — Generative AI for Agile Project Management (C324)

Everything you need for the 12 hands-on labs. Every generative feature in this
course runs in a **web browser** — the tools are general-purpose AI assistants,
so there is **nothing to install** and **no coding** involved.

## Accounts & software

| Tool | What it's for | Notes |
|---|---|---|
| **ChatGPT** (chat.openai.com) | A general-purpose AI assistant for drafting and analysing agile artifacts | A free account is enough to follow the labs |
| **Claude** (claude.ai) | A general-purpose AI assistant; strong on long context and careful drafting | A free account is enough; useful for pasting in longer briefs and backlogs |
| **Gemini** (gemini.google.com) | Google's general-purpose AI assistant | A free account is enough; handy if your team lives in Google Workspace |
| **A modern web browser** | Runs all three assistants | Chrome, Edge, Safari or Firefox |
| **Internet connection** | The assistants run in the cloud | Required for every step |
| **A documents / notes folder** | Where you save each reviewed output and prompt | Keep it all in one `Tempo-2.0-Playbook` folder |

You do **not** need all three tools — any one is enough to complete every lab.
Where a lab asks you to compare the same prompt across tools, use whichever two
you have. The prompting and review skills transfer across all three.

## The two habits that run through every lab

1. **Prompt, review, own.** Give a structured prompt (role · context · task ·
   format · constraints), review the draft for accuracy, fit, invented facts,
   fairness and clarity, and take ownership of the result. The AI never decides.
2. **Responsible use.** Never paste confidential customer data, personal
   information, credentials or proprietary code into a public assistant;
   fact-check specifics; and be transparent with your team about what was
   AI-assisted. You build this into a checklist in **Lab 3** and keep it open for
   the rest of the course.

## Before Lab 1 — confirm your setup

1. Open at least one of **chat.openai.com**, **claude.ai** or **gemini.google.com**
   and **sign in**.
2. Send a simple prompt — *"Hello, are you ready to help me with agile project
   management?"* — and confirm you get a reply.
3. Create a project folder called **`Tempo-2.0-Playbook`** for all your work.
4. Open the **Tempo 2.0 project brief** in [reference-pack/](reference-pack/).

If any of these is missing, tell the trainer at the start of the day.

## The connected project

Every lab builds one section of the **Tempo 2.0 Agile AI Playbook** for the
fictional habit-tracking app **Tempo** (see [reference-pack/](reference-pack/)).
Keep every reviewed output and prompt in your `Tempo-2.0-Playbook` folder so the
playbook stays together. There is **no assessment** — each lab verifies itself
with a **Test it** step.
